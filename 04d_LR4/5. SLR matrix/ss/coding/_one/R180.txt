To address these issues, a physics-informed neural network (PINN)-based edge-cloud collaborative digital twin (D T) architecture (Kazemi Naeini et al., 2025) has been developed. Thus, it is a hybrid approach that combines physics-based modelling with machine learning (ML) that allows real- time emulation, monitoring, and predictive analysis of signalling equipment. The framework can be broken down into three layers: physical asset layer (IoT sensors for data collection), edge layer (localised devices like FPGAs and microcontrollers running lightweight PINN models for low-latency anomaly detection), and a cloud layer (computati onally intensive PINN models for model refinement and system-level optimisation) (Yang et al., 2024; Zia et al., 2025). The PINN structure encodes physical laws at the neural level and requires less data, and makes appropriate predictions even if there is no t much data. The edge-cloud sync mechanism ensures a smooth data flow, where the edge performs instantaneous calculations and the cloud updates every so often to enhance the precision of predictive computations.
