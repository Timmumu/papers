## Abstract summary
Supervisory Control and Data Acquisition (SCADA) systems are critical for managing large-scale industrial facilities, yet their increasing connectivity exposes them to sophisticated cyberattacks, with a reported 44% rise in incidents by 2023. This study addresses the challenge of intrusion detection in SCADA systems by evaluating four advanced deep learning models, DCNv2-MoE, EntityEmbeddingMLP (EE-MLP), RTDLResNet, and Temporal Convolutional Network (TCN), for multi-class attack classification. Using a custom SCADANet dataset, generated in a virtualized lab environment with nine attack scenarios (e.g., HTTP flood, SQL injection, port scan) and normal traffic, we applied comprehensive preprocessing to tackle class imbalance, high dimensionality, and temporal dependencies.
