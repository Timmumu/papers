# Moe, S.J.S et al. (2026) — Optimizing Federated Learning based on Weighted Hyperparameter Aggregation in Energy-constrained Building Construction

## Abstract summary
Federated learning (FL) is compelling for construction safety because sensitive, site-specific data can remain on devices; however, hyperparameter optimization (HPO) in FL is often impractical on resource-constrained edge nodes due to multi-round tuning and communication overhead. Existing FL-HPO approaches (e.g., weight sharing and server-only selection) either incur iterative client-server loops or underutilize client heterogeneity, thereby raising privacy and governance concerns. We propose an asynchronous, one-shot local Bayesian optimization on each client using a small data subset, followed by loss-weighted aggregation of client-proposed hyperparameters on the server to produce a single global set for collaborative training. **Key evidence (AG):** One-shot local Bayesian optimization + loss-weighted hyperparameter aggregation for federated learning (FL), integrated into a Digital Twin platform for device registration, orchestration, and telemetry (Jeju National U, Cluster Computing 2026): clients optimise hyperparameters locally on small data subsets, the server aggregates a single global set for collaborative training; training-method agnostic; evaluated on MNIST/EEGEyeState/Weather plus a private worker-safety dataset; 6.44% average end-to-end improvement, faster convergence, lower MAE vs simple averaging, reduced response time on Raspberry Pi AIoT clients; on-device inference supports near-real-time safety alerts to supervisors and wearables. One-way telemetry->prediction->alerts; FL retraining loop implemented but no convergence criterion and no physical actuation.

**AH — strength & gap filled:** Fills the FL-HPO gap for energy-constrained construction edge nodes: one-shot local Bayesian optimisation removes iterative client-server tuning rounds, and loss-weighted aggregation of client-proposed hyperparameters yields a single global set that improves convergence, accuracy/MAE and Raspberry-Pi response time (+6.44% end-to-end) while keeping site-sensitive safety data on-device for privacy.

**AI — deficiencies & future work:** Evaluation spans three public datasets plus one private worker-safety dataset rather than a longitudinal on-site deployment; convergence of the aggregated hyperparameters is not theoretically characterised; communication/privacy of shared hyperparameters and scalability to large fleets are discussed but not empirically bounded.
