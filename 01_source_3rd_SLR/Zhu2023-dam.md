## Abstract summary
Comprehensive evaluation of dams in a dynamic and proactive way is accepted as an effective strategy to improve dam safety. However, there is a lack of efficient and standardised approaches for managing monitoring-related information that can help to provide dynamic and reliable information for continuous dam evaluation. With the importance of digital twins (DTs) being proven in better data integration and interoperability, a DT-based approach for comprehensive dam evaluation and its data integration method based on extended industry foundation classes (IFC) are provided in this study. This paper presents a new data structure and corresponding data classification strategy, using which information required for continuous evaluation can be effectively organised. **Key evidence (AG):** Dam digital twin (Jiangya dam, 131 m gravity dam) for automated continuous safety evaluation: extended IFC data schema (IfcDSMSystem/IfcMonitoringItem/IfcSensorAssembly) integrates DSM monitoring information (deformation, seepage, stress, environment); HST statistical models set baselines; multi-rule cloud-reasoning model evaluates monitoring points, multi-dimensional cloud model + improved CRITIC (no-human weights) aggregate to five-grade dam safety status. Case: continuous evaluation Jan–Sep 2019 → "basically normal". One-way monitoring→automated evaluation→human decisions (preventive maintenance); statistical models are regression fits, no self-improvement loop.
