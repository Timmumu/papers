## Verified Evidence

### BIM-IoT-Data Mining DT Framework (Abstract & Section 1)
^sec-framework

> Closed-loop digital twin framework integrating BIM, IoT, and data mining (DM). IoT captures real-time inspection data from devices. 4D visualization and task-centered/worker-centered process models simulate both task execution and worker cooperation. Process mining (fuzzy miner) foresees bottlenecks; ARIMAX time-series model predicts next-phase finished tasks. Validated on a practical BIM-based project with large inspection data from IoT devices.

**Method:** BIM + IoT + DM integration; fuzzy miner for process bottleneck detection; multivariate ARIMAX for task prediction. Demonstrated tactic decision-making that prevents failures and optimizes work/staffing arrangements.

**Supports:** LR_GPT.md §5.2, §5.5 — data-driven DT framework for advanced project management.

### Results & Validation
^sec-results

> "Results show that possible bottlenecks in the current process can be foreseen using the fuzzy miner, while the number of finished tasks in the next phase can be predicted by the ARIMAX model." Single-project validation. Data-driven DT enables "tactic decision-making to not only prevent possible failure in advance, but also arrange work and staffing reasonably to make the process adapt to changeable conditions."

### Limitations
^sec-limitations

> Single-project validation; data mining limited to structured data (BIM parameters, schedules); framework complexity may hinder practical adoption. Authors note: "more complex cases with multiple data streams will be used to test the developed framework, and more detailed interpretations with the actual observations of construction activities will be given" in future work.
