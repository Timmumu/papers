## Abstract ^sec-abstract
Reviews the development of Digital Twin technologies in manufacturing systems and processes. Summarizes DT definitions, proposes a DT reference model that systematizes development methodology, surveys representative applications under that reference model, and identifies outstanding research issues for DT-driven smart manufacturing in the Industry-4.0 context. ^p1

## Method ^sec-method
Narrative literature review structured around a proposed DT reference model. No primary data; synthesis-driven taxonomy. ^p1

## Key Findings ^sec-results

- DT-driven smart manufacturing requires an explicit reference model spanning physical entity, virtual entity, services, data and connections — not a single 3D model. ^f1

- Most reviewed applications align with subsets of the reference model; few populate all five layers, exposing a fragmentation pattern that recurs in AECO DT literature. ^f2

- Open research issues — high-fidelity modeling, real-time data fusion, service-based encapsulation and security — are systemic, not domain-specific. ^f3


## Discussion & Implications ^sec-discussion
A widely cited reference model that AECO DT studies routinely adapt. The fragmentation pattern documented here is structurally identical to what the SLR observes in construction DTs, supporting cross-domain transferability arguments. ^p1
