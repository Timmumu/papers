## Abstract ^sec-abstract

Maintaining a comfortable indoor environment is essential for occupant well-being, but traditional inspections rely on manually entered target coordinates and so scale poorly. The paper proposes a semantic-navigation approach for robotic indoor environment quality (IEQ) inspection: a revised RandLA-Net plus KNN constructs an object-rich semantic map, an object-instance reasoning module extracts target coordinates from human-like language commands, and a semantics-aware A* planner produces safer, more efficient paths through richer robot–environment interaction. Experiments report ≈0.08 m position accuracy for objects in the semantic map, successful coordinate extraction by the reasoning algorithm, and paths that stay farther from obstacles and clutter while consuming less computation than baseline A*. ^p1

## Introduction & Background ^sec-intro

Manual IEQ inspection is labour-intensive, error-prone, and produces fragmented data that is hard to integrate with building models or DT pipelines. Existing autonomous robots usually require precise pre-specified coordinates, which presupposes the very spatial knowledge the inspection is meant to obtain. ^p1

The work positions itself in the gap between geometry-only SLAM/path-planning and semantically grounded, language-driven robotic agents that can be commanded in occupant- or operator-friendly terms (e.g., "measure CO₂ near the meeting-room desk"). ^p2

## Method ^sec-method

1. **Semantic map construction** — a revised RandLA-Net performs point-cloud semantic segmentation; KNN aggregates segmented points into object instances rich in semantic labels and geometry. ^p1
2. **Object-instance reasoning** — given a natural-language inspection command, the reasoning module identifies the referenced object instance(s) in the semantic map and extracts target coordinates. ^p2
3. **Semantics-aware A\*** — the planner uses object semantics (clutter, obstacle class, walkability) to bias the cost field, producing safer and computationally cheaper paths than a geometry-only A*. ^p3
4. Validation through indoor experiments measuring object position accuracy, coordinate-extraction success, and path quality vs. baseline planners. ^p4

## Key Findings ^sec-results

- Object position accuracy in the constructed semantic map: ≈0.08 m. ^f1
- Object-instance reasoning successfully extracts target coordinates from human-like language commands. ^f2
- Semantics-aware A* generates paths farther from obstacles and cluttered regions than baseline A*. ^f3
- The semantic planner reports lower computational time than baseline A*. ^f4

## Discussion & Implications ^sec-discussion

Embedding semantic knowledge inside both the map and the planner converts robotic inspection from a teleoperated tool into a language-addressable cognitive agent — a building block for closed-loop FM where a DT can dispatch inspection missions on demand. ^p1

The reported sub-decimetre accuracy and obstacle-aware paths are reasonable for IEQ sensing (where ±10 cm is acceptable for CO₂, PM, T/RH) and reduce the human burden of authoring inspection scripts. ^p2

## Conclusion ^sec-conclusion

Semantic navigation, combining semantic mapping, instance reasoning from natural language, and a semantics-aware planner, raises robotic IEQ inspection from coordinate-driven automation to language-driven cognitive operation. ^p1
